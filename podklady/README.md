# Podklady — Fresh Burger Kladno

Stažené podklady ze stránek **freshburger.cz** (stav ke dni 4. 5. 2026).

## Obsah složky

- `menu.md` — kompletní jídelní lístek (kategorie, položky, ceny, popisy, alergeny)
- `o-nas.md` — text „O nás", info o rozvozu, sociální sítě, aplikace
- `kontakty.md` — adresa, telefon, e-mail, otevírací doba, IČO, provozovatel
- `texty-z-webu.md` — všechny texty z původního webu (hero, sekce, patička)
- `galerie/` — fotky z galerie webu (7× jídla v plném rozlišení + náhledy v `nahledy/`) + foto provozovny
- `ostatni/` — logo, favicon, screenshot aplikace, badge Google Play, PWA, mapa rozvozu
- `menu-data.json` — surová data jídelního lístku z API webu (záloha)
